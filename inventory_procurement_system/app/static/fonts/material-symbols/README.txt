# Local Font Files

Place the following font files in this directory:

1. **MaterialSymbolsOutlined[opsz,wght,FILL,GRAD].woff2**
   - Download from: https://fonts.google.com/icons?icon.set=Material+Symbols+Outlined&icon.style=Outlined
   - Used by: `.material-symbols-outlined` class across all templates

2. **Inter[wght].woff2** (optional)
   - Download from: https://fonts.google.com/specimen/Inter
   - Used by: `fontFamily: ["Inter"]` in Tailwind config

Without these WOFF2 files, icons will fall back to browser default fonts and may not render correctly.
